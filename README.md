# Lumia Pulse

Lumia Pulse is the node and rewards layer of the Lumia ecosystem — node ownership,
staking, reward distribution, referral programs and the dashboard through which
participants track them.

This repository is the public home of Pulse's release history. The product itself is
developed in a private repository; what ships from it is documented here.

## What's in this repository

| | |
|---|---|
| [CHANGELOG.md](./CHANGELOG.md) | What shipped, and when |
| [Issues](https://github.com/LumiaChain/lumia-pulse/issues) | Bug reports and feature requests |
| [Discussions](https://github.com/LumiaChain/lumia-pulse/discussions) | Questions, ideas and proposals |

## Areas

Release notes are labelled by the part of the product a change affects.

- **dashboard** — the participant-facing web application
- **api** — the service behind it
- **admin** — internal operations tooling

## Reporting an issue

Open an issue using one of the templates. For anything security-sensitive, do not open a
public issue — write to the Lumia team directly.
